# Dossier de presse

**Zone de prépublication — hors build public.**

Éléments destinés à une sollicitation presse. Aucune retombée média à ce jour.

## Règles applicables à ce répertoire

- Aucun fichier de ce répertoire n'entre dans le build public (`dist/`).
- Tout actif porte un statut : `TEMP`, `REVIEW`, `APPROVED` ou `PUBLIC_READY`.
- Un actif n'est référençable par une page publique qu'au statut `PUBLIC_READY`
  avec `public_allowed` à `true`.
- Aucun fait non prouvé, aucune relation non établie, aucun résultat non réalisé.
- Aucun secret, aucune donnée bancaire, aucune donnée personnelle sensible.

## État

Architecture créée. Contenu source à produire par le propriétaire fonctionnel compétent.
